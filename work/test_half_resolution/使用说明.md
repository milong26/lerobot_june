# 选择时间
要求：部署时候的时间（-4step金额0step的observation和action对齐）
state反映的物理状态本身滞后，send_action发送完sync_write写完就返回
state_after_send_action 时间差至少200ms。
采集的时候也是这个时间差： state[i]和action[i]同步采集，state[i+1]和action[i]之间仍然有误差，teleoperation的时候就一直修正
main_controller：
send_action后记录state和对应时间戳，并找到距离时间最接近-133ms的state打包payload发送，
最后一步send_action应该继续，因为采集的时候 采集完a[0]和s[0]以后，a[0]对应的s[0]是[-1]执行a[-1]到中途的结果
