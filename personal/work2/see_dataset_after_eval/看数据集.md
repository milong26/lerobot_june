# 功能说明
实现的是一个针对 LeRobot/SmolVLA/MetaWorld 数据集和训练结果的 embedding 分析与子集质量评估工具。它的目标不是训练模型，而是在训练之后分析：模型看到的数据是否具有代表性，embedding 是否编码了任务状态信息，以及 Ours 子集选择方法相比 Random/Uniform 是否保留了有效的信息。

整体上，这套代码回答几个问题：

模型 embedding 是否包含环境状态信息？
embedding 空间是否反映真实物理状态距离？
训练数据子集（Random、Uniform、Ours）覆盖状态空间的能力如何？
Ours 方法选择的数据是否只是重复 Uniform 的覆盖，还是有独立价值？
attention/模型行为分析之前的数据选择是否合理？

所以整个文件夹有好几个代码，分别处理一些功能
1. analyze_dataset_embedding.py：把已有的episode embedding、MetaWorld环境状态metadata以及Random/Uniform/Ours三个数据子集按照episode_index完成对齐，构造三种主要表示：global、wrist和combined。然后分析embedding是否真正包含任务状态信息、分析Random、Uniform和Ours三个训练子集的质量根据coverage来看的、做Fixed SIC和随机bootstrap统计比较（这个是为了改进之前的our方法，如果这个方法好的话，有可能可以替代之前的our方法，做到成功率更高）。最后把所有的分析汇总成H1，H2,H3三个假设。
